# ATCU 0.0.1 - Army Template and Conform Universal

First single-player beta candidate for Victoria II 3.04.

Create army compositions, recruit them through the normal game queue,
and use Conform to detach extras and build the regiments an army lacks.
Conform recruits within land reach and tracks new reinforcements during
the current session so they can march and merge into the selected army.

The same files-only package has passed short gameplay checks on vanilla,
HPM 0.4.5, DoD Fan Fork and TGC 2.5.2. TGC was checked with V2DLL 5.82.
Other mods and multiplayer remain untested. Culture filters and a
continent selector are planned.

Download `ATCU-0.0.1-candidate.zip`, extract it, and read `INSTALL.txt`.
No installer or scripts required. The archive includes an optional loader
for clean installations and the plugin for an existing V2DLL setup.
V2DLL users keep their existing root loader. Select only ATCU and the base
mod; untick old Army packages.

The tested gameplay DLL remains internal build 0.10.4, so that version in
the log is expected. Template libraries are local files. Conform tracking
does not survive save/reload; previously queued units finish separately.

Candidate status: license undecided, bundled-art publication status still
to be recorded, and a second-PC recipient test remains outstanding.
This is prepared release text, not an announcement that publication has
occurred. Proposed GitHub tag: `v0.0.1`; mark the eventual release as a
